User Onboarding from Email

n8n automation: Gmail → parse details → root login → create user in the Spring Boot app

How it works

#StepWhat happens
1Onboarding EmailChecks Gmail every minute for unread emails with subject User onboarding
2Extract DetailsReads Name, Department, Age and Email from the body
3ConfigHolds the app URL (baseUrl) and the root username
4-7Sign in as rootGET /login → read cookie and CSRF token → POST /login → keep the new JSESSIONID
8-10Submit new hireGET /onboarding → read a fresh CSRF token → POST the user details
11Succeeded?A 302 redirect to / means success
12Mark Email ReadStops the email from being processed again
13Onboarding FailedStops with an error; the email stays unread for a retry

Session flow

n8n  --GET /login------------------------------------->  App   200 + cookie A + csrf T1
n8n  --POST /login (root, csrf T1, cookie A)---------->  App   302 -> /onboarding + cookie B
n8n  --GET /onboarding (cookie B)--------------------->  App   200 + csrf T2
n8n  --POST /onboarding (details, csrf T2, cookie B)-->  App   302 -> /  (user created)

Setup notes

  • The app runs on localhost:8081 and is made public with cloudflared tunnel --url http://localhost:8081.
  • Quick tunnel addresses change on every restart. Update Config → baseUrl each time, then republish.
  • All HTTP steps use Full Response, with Follow Redirects off and the Cookie header passed manually.
  • Import the workflow in n8n with … → Import from File, then reconnect the Gmail credential.
